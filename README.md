# Jaydeep Deore — AI/ML Engineer & Systems Developer Portfolio

A high-end, 1:1 replica of the Codarox design system built with **React 19**, **Three.js (WebGL GLSL Shaders)**, **TypeScript**, and **Vite**. Strictly tailored to Jaydeep Deore's authentic credentials, achievements, and engineering projects.

---

## ⚡ Single Command Run (१ कमांडवर रन करा)

टर्मिनलमध्ये खालीलपैकी कोणतीही **१ कमांड** टाका, सर्व्हर सुरू होईल आणि ब्राउझर **आपोआप ओपन होईल**:

```bash
npm start
```
*किंवा*
```bash
npm run dev
```
*किंवा Windows वर थेट:*
```cmd
.\run.bat
```
*(किंवा `run.bat` फाइलवर थेट डबल-क्लिक करा)*

## 🌟 Key Features

1. **Split-Door White Page Loader** — Split sliding doors that reveal the site upon asset load.
2. **Three.js WebGL Particle Wave Canvases** — 60 FPS GPU-accelerated GLSL wave shaders across Welcome, Contact, and Footer.
3. **Animated SVG Monogram** — Path-tracing brand monogram in the hero.
4. **Floating Capsule Header** — Glassmorphic floating nav capsule with smooth hide/reveal on scroll and line-morphing mobile menu.
5. **3-Digit Numeric Scroll Indicator (`000` to `100`)** — Fixed right-edge indicator with automatic dark mode switching.
6. **Circular Progress Back-To-Top** — Dynamic SVG stroke-dashoffset tracking scroll position.
7. **Lighthouse Quality Dashboard** — Live animated counter easing from 0 to 100 for Performance, Accessibility, Best Practices, and SEO.
8. **Engineering Lab (Dynamic Memory Visualizer)** — Live 60 FPS Canvas heap memory simulator with dynamic block allocation and coalescing.
9. **Quick Contact Card & Form** — Interactive message form and direct mailto / telephone links.
10. **CV Verified** — Lovely Professional University (CGPA 7.8), HackerRank #1 in C Domain, 200+ LeetCode, MedBook XAI, Smart Krishi AI SIH 2025, EduGenie RAG.
11. **Moody Monochrome Portrait** — High-fashion black-and-white editorial portrait in the About Me section.
